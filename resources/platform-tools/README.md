# Platform tools

Release builds stage Google's official Android SDK Platform Tools here by platform and architecture:

```text
darwin-arm64/adb
darwin-arm64/fastboot
darwin-x64/adb
darwin-x64/fastboot
win32-x64/adb.exe
win32-x64/fastboot.exe
linux-x64/adb
linux-x64/fastboot
```

NexusFleet reports whether it resolved a bundled or system installation. It never accepts a tool path from the renderer.
